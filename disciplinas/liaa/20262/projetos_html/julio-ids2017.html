Resumo

Júlio, aluno do segundo semestre de Ciência da Computação, definiu com ajuda do ChatGPT um projeto de classificação de tráfego de rede em benigno ou potencialmente malicioso usando a versão corrigida do CIC-IDS2017. O MVP é uma ferramenta de apoio ao profissional de segurança: o usuário seleciona um CSV, os dados passam pelo mesmo pré-processamento do treino e cada registro é classificado, com resumo dos resultados; o critério de sucesso é pelo menos 90% de recall e F1. Ele planejava comparar Dummy, Random Forest e XGBoost. O professor alertou que o dataset é de 2017 e não representa o tráfego atual, e propôs comparar os modelos clássicos com uma LLM classificando o dataset diretamente, incluindo custos. Depois de 15/09, o projeto não voltou a ser apresentado nas gravações.
